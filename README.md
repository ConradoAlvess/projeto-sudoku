**SUDOKU - PROJETO ACADEMICO**

Sobre o projeto:

Este projeto tem como objetivo desenvolver uma aplicação web utilizando **HTML, CSS e JavaScript**, aplicando os conhecimentos adquiridos durante o curso de Desenvolvimento Front End.

O desenvolvimento será realizado em equipe, utilizando o Git e o GitHub para compartilhamento de código, controle de versão e colaboração entre os integrantes.

Tecnologias utilizadas:

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e layout.
- **JavaScript:** funcionalidades e interatividade.
- **Git e GitHub:** versionamento e colaboração.



Trabalho em equipe:

Cada integrante ficará responsável por uma parte do desenvolvimento. As alterações serão registradas por meio de commits no GitHub, mantendo o histórico de desenvolvimento do projeto.

Como executar:

1. Clone o repositório para o seu computador.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador para visualizar a aplicação.

Objetivo acadêmico

Projeto desenvolvido em grupo para fins educacionais, com foco na prática de desenvolvimento web, organização de código e trabalho colaborativo utilizando ferramentas de versionamento.
